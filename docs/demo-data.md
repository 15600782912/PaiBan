## 推荐体验

1. 选择“测试主播小林”，查看个人页的多公司汇总与冲突。
2. 查看“排班”页并切换公司/直播间。普通成员只能查看本人记录，有排班授权的成员能查看公司安排。
3. 切换“星河传媒运营”，从有效排班卡片点击复制，尝试明天、下周、自选日期或按星期重复；预览后整批保存，有冲突会集中确认。
4. 切换其他公司运营账号，观察各自只属于一家公司的授权；五个账号都在给小林排班。
5. 阿辰可查看所有公司并授权成员排班。取消记录默认收起，通过“查看已取消（N）”展开。
6. 第二家公司含待分配记录，第三家含取消记录，第四家在基准日前一天含停用直播间历史场次。
7. 新用户可以直接创建公司，或用创建者在公司页复制的邀请码加入别人的公司。

## 重新生成

会先备份，再清空当前配置的本地数据库业务数据（包括薪资和个人工时），保留数据库结构、迁移版本、配置和已有备份。仅在显式开启测试登录的开发环境允许执行。

在 `backend/` 目录运行：

```powershell
..\.venv\Scripts\python.exe -m app.demo_seed --reset
```

默认按执行当天北京时间生成。需要固定演示日期时可加 `--date 2026-10-26`。

工具先在临时数据库调用正常业务接口构建并验证，再锁定本地写入、在线备份、在单一事务内替换数据。构建失败不影响原数据，安装中途失败回滚原数据；重置结果会输出备份路径和统计。没有新增清空数据的HTTP接口，不修改微信凭证或JWT密钥。

原生编译和设备交互检查需在装有微信开发者工具的机器执行。
