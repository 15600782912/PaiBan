# 直播间排班版本验收

## 页面与账号

- [ ] 默认个人页，导航依次为个人、公司、排班；无薪资入口或个人记工时功能。
- [ ] 公司页只显示公司信息、角色、切换、加入/创建及公司管理入口，无日期栏和排班列表。
- [ ] 邀请码仅创建者可见；普通主播无法查看公司其他主播信息。
- [ ] 登录、个人页改名/退出、账号切换及迟到响应处理正常。
- [ ] 公司胶囊下拉选项可滚动，外部点击和页面滚动关闭，不影响日期栏布局。

## 直播间与当天排班

- [ ] 排班页默认今天，可选公司、日期及前后一天；直播间下直接展示当天主播安排。
- [ ] 创建者和可排班成员看到有效空直播间提示“当天暂无排班”；普通主播只看到本人有记录的分组。
- [ ] 直播间管理支持新增、改名和停用，长名称、多直播间、小屏布局正常。
- [ ] 新排班预填所选房间和日期，必须明确选择主播和有效直播间。
- [ ] 旧记录显示待分配，编辑可分配；停用直播间保留历史但不能重新安排，只能取消或改派。
- [ ] 已退出主播的历史记录不自动改派；取消记录可查看，不参与冲突。
- [ ] 跨午夜场次在两天正确显示当天时段和时长，标明承接前日或延续至次日。

- [ ] 排班页公司旁有直播间胶囊，默认全部；支持单个、空直播间、停用历史和待分配筛选，不额外请求接口。
- [ ] 公司与直播间菜单互斥，外部点击/滚动/切页关闭；换公司重置全部，换日期保留有效选择，失效回退全部。

## 冲突与可靠性

- [ ] 不同主播同直播间重叠、同主播不同直播间重叠、两类同时重叠均清楚提醒；一次确认后保存。
- [ ] 取消确认不保存；相邻时段不提醒；取消排班后冲突标记更新。
- [ ] 普通主播冲突提示不泄露其他主播姓名/时间；运营看不到跨公司的安排。
- [ ] 修改排班的版本校验、网络超时冻结内容、同键重试不重复创建正常。
- [ ] 新增/改名/停用遇到断网或账号切换，不误提交给新账号。

## 升级与发布

- [ ] 升级0004前在线备份，升级后历史排班的时间、备注、主播和状态保持不变，直播间关联为空。
- [ ] 数据库完整性、外键检查、后端健康检查正常；迁移后重启后端。
- [ ] 前后端自动测试、原生WXML/WXSS及JS/JSON检查通过。
- [ ] 微信开发者工具交互预览及真机HTTPS、真实登录、隐私配置另行验收，未执行项不标完成。

## 身份、复制与取消折叠版本

- [ ] 测试登录直接展示账号列表，无身份分类；取消/返回不发起登录、不覆盖原会话，微信登录不变。
- [ ] 用户能自行创建/不创建公司、邀请码加入，权限按公司生效；创建者可授权/撤销其他成员排班权限。
- [ ] 公司和成员页显示创建者、可排班成员、普通成员，邀请码提示与授权按钮文案一致。
- [ ] 从有效场次复制到明天、下周同一天、自选多日期；原场次不变，跨午夜/多日跨度保留。
- [ ] 按日期范围和星期生成最多60场，预览日期与时间；修改任意字段后必须重新预览。
- [ ] 批次内及已有排班冲突一次确认；取消不创建，任一成员/直播间/参数无效整批回滚。
- [ ] 超时冻结原批次与去重标识，同键重试不重复，切换账号清空待提交批次。
- [ ] 两个列表默认隐藏取消记录，当前筛选取消数量正确；只有取消记录时提示明确，展开仍按直播间分组。
- [ ] 切换公司、日期、账号恢复收起，编辑返回仍停留原公司、直播间和日期。
- [ ] 演示数据不重新生成，仅原测试管理员改名为测试用户阿辰，ID/公司所有权保持不变。
