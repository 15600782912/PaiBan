# 个人排班首页调整记录

依据：用户批准的“新增个人排班首页，调整公司页分工”计划。

- 默认首页及导航调整为个人、公司、薪资；个人只读汇总本人排班，支持周、单日和公司筛选。
- 公司信息为主要内容；管理员/运营保留公司排班管理，主播前往个人页。
- 账号修改姓名/退出登录从公司移到个人，复用原有登录与会话保护。
- 复用现有接口，无后端、数据库结构及历史数据修改。
- 原目录无Git仓库，直接原位实现；本次进度独立于之前公司首页变更。
- 回归测试覆盖旧响应、401、账号切换、公司表单隔离及筛选；测试先失败后通过。
- 发现旧公司提交失败可能清空新账号草稿，已复现并修复。
