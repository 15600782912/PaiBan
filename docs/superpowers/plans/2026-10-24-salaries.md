# 个人薪资管理 Implementation Plan

> Use executing-plans inline and test-driven-development; one independent review at the end.

**Goal:** Add private named salary presets and use a salary dropdown at all work-log entry points.
**Spec:** User-approved plan in this conversation, including legacy price migration and preserved historical snapshots.

## Implementation tasks
1. Write failing tests for salary CRUD ownership, idempotency, snapshots, stale/deleted selection, defaults binding, migration de-duplication and zero rates.
2. Add salary model and revision0003. Soft-delete presets, retain their historical IDs; explicitly invalidate linked defaults on deletion. Snapshot name/rate on log creation or deliberate salary replacement.
3. Implement private salary APIs. Resolve selected salaries server-side and compare expected integer-fen price; preserve existing raw-price API callers and idempotency fingerprints.
4. Write executable frontend tests for salary selection/preservation, empty lists, stale selection refresh without lost duration/note, management retries and account isolation. Add native Salary tab, management form and dropdowns in personal/editor.
5. Back up before local migration, run all tests and native compilation, apply migration and inspect devtool rendering; independent review, regression fixes, documentation.

## Invariants and rulings
- No Git repository: use supplied workspace; no branch/commit automation.
- Salary name/rate changes only affect future selections; old log snapshots survive changes/deletion.
- Historical editors begin on an explicit "keep original salary" option, never silently select the first live preset.
- Deletion is logical (deleted flag); defaults lose preset binding but retain duration/note and last numeric price for old-client compatibility. New UI requires reselection.
- Monetary bounds and rounding unchanged. Presets are unique identities, names/rates need not be globally unique.
- Migration generates one preset per user/distinct non-null legacy rate, named 历史时薪80.00元, and associates old logs/defaults without altering monetary values.
